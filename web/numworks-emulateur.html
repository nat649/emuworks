ROM / Firmware

Image de firmware éditable. Modifie le JSON puis Flasher — l'émulateur redémarre avec ta configuration. Tout est stocké localement dans ce navigateur.

Champs : boot (logo), angleUnit (deg/rad/grad), exactResults, brightness (0–1), color (black/white), battery, apps[] (name, color, hidden), scripts (fichiers Python).

Le vrai Epsilon (WASM)

Pour faire tourner le système officiel compilé depuis les sources NumWorks :

git clone https://github.com/numworks/epsilon cd epsilon # dépendances : emsdk (version dans .emsdk-version), python3, node make PLATFORM=web epsilon.html -j8 # → epsilon/output/release/web/epsilon.html

La cible PLATFORM=simulator produit un binaire de bureau (SDL2). « Modifier la ROM » revient alors à modifier les sources C++ et à recompiler — il n'y a pas de ROM séparée dans le simulateur. Sources : github.com/numworks.
