# EmuWorks quick start

Launch EmuWorks from a writable folder without spaces, such as C:\EmuWorks. Install Renode 1.16 separately. The current 0.2.0 build needs no Node.js; self-contained packages include .NET.

Use Library to select Core or Code, then Use selected firmware and Start calculator. Core provides arithmetic and session history. Code provides MicroPython and independently stored source scripts. Import firmware accepts a matching N0110 internal/external binary pair supplied by you.

Settings provides integer screen zoom, PC key mappings and optional update checks. The Scripts tab includes manual backups and a dated backup browser. Updates opens the official release page after checking its version. The Journal tab reports startup and synchronization errors.

Preserve rom/, firmwares/ and settings.json when updating. Documentation: docs/windows-release.md and docs/fiabilite.md. Core and Code sources are maintained separately; their original compiled images and notices are included here. Third-party calculator firmware is excluded.
